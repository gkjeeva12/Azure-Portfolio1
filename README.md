# Azure Portfolio - Static Web App

This portfolio is a fully static website designed for Azure Static Web Apps.

## Contact form

The contact form uses FormSubmit to forward submissions to **jjee2577@gmail.com**.
There is no Flask backend, Azure Function, SMTP password, or email credential in this repository.

On the first submission, FormSubmit may send a confirmation email to the destination address. Click the confirmation link once to activate the form.

## Deploy

Use Azure Static Web Apps with:
- App location: `/`
- API location: leave empty
- Output location: leave empty

The site can also be hosted on any static web host.
